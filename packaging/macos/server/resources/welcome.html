Better Backup Server makes this Mac the place your other machines back up to.

This installs:

  • the server, which runs in the background, also when nobody is signed in;
  • the installer of the backup agent for other Macs, which the server's web page hands out;
  • the bb and bb-server commands, for Terminal. You do not need them: everything is set up on the server's web page.

The backups are kept in /Library/Application Support/better-backup/repo to begin with. To keep them on another disk, change the folder on the web page under Settings, before the first backup.
