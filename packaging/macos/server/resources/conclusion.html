The server is running. Its web page is opening in your browser: https://localhost:8443/

  1. Your browser warns about the certificate, because the server makes its own. Choose to continue.
  2. Create the administrator's name and password.
  3. Download the repository key when the page asks, and keep it somewhere other than this Mac.
  4. Under Settings, add the name or address other machines reach this Mac by, and choose the folder for the backups.

macOS may ask whether the server may accept incoming connections. Allow it, or agents cannot reach it.

To remove the server later, run sudo bb-server-uninstall in Terminal. The backups are kept unless you ask for them to be deleted.
