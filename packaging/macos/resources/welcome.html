Better Backup backs this Mac up to your better-backup server.

This installs:

  • the backup agent, which runs in the background, also when nobody is signed in;
  • the Better Backup app, which connects this Mac to your server and shows how the backups are going;
  • the bb-agent command, for Terminal.

To connect this Mac you need an enrollment code. Get one from your server's web page, under Add an agent.
